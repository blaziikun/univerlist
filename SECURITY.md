# Security

Found a way to get at someone's data, run code in the app, or run up the site's bill? Please tell me privately first:
**GitHub › this repository › Security › Report a vulnerability** (private vulnerability reporting). Please don't open a
public issue for it. I'll answer within a week and credit you in the fix, if you'd like.

What's in scope: the app (`src/`), the Worker (`worker/`: the proxy and Account & sync) and the official extensions
(`extensions/`). How the app is protected, point by point, is in [docs/security.md](docs/security.md).
